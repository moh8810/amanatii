# Amanati Launchpad

Design a premium, modern, minimal Arabic RTL landing page for a logistics and package-holding startup called:



أمانتي | AMANATI



Important



This is UI/UX only.



Do NOT build a backend.



Do NOT create a database.



Do NOT create authentication.



Do NOT create dashboards.



Do NOT create APIs.



Do NOT create complex functionality.



Do NOT over-engineer the project.



I only want a beautiful, polished homepage/landing page so I can evaluate the visual identity and design of the brand.



Keep the implementation simple and lightweight.



---



Brand Concept



AMANATI is a local Yemeni service that combines:



- Package holding / Amanat

- Shipping between cities

- Package receiving

- Pickup points

- Simple shipment tracking



The company has one physical center.



Customers can leave packages at the center as amanat.



Merchants can send their customers' orders to the AMANATI center.



For inter-city shipping, AMANATI works with trusted drivers who transport packages to agreed pickup points such as local stores or groceries.



The website will eventually allow customers to track their shipments.
